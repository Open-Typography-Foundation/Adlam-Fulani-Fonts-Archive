> Curated and sovereignly maintained by **Mohammad Golamrabbii** for the **Open Typography Foundation**.

Modern indigenous West African alphabet created by Ibrahima and Abdoulaye Barry in 1989 for the Fulani language, featuring ADLaM Display and Noto Sans Adlam.

---

## 🌟 Typographic Specimen

```text
𞤋𞤲𞥆𞤢𞤥𞤢 𞤴𞤭𞤥𞤩𞤫 𞤬𞤮𞤬 𞤲𞤮 𞤲𞤶𞤭𞤦𞤭𞤲𞤢𞥄 𞤫 𞤲'𞤣𞤫𞤪 𞤰𞤫𞤤𞥆𞤭𞤼𞤢𞥄𞤪𞤫
```

## ⚡ Fast Installation

### Linux & macOS (Bash)
```bash
curl -fsSL https://raw.githubusercontent.com/Open-Typography-Foundation/Adlam-Fulani-Fonts-Archive/main/install.sh | bash
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/Open-Typography-Foundation/Adlam-Fulani-Fonts-Archive/main/install.ps1 | iex
```
